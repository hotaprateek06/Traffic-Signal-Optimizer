# 🚦 Traffic Signal Optimizer (DAA Project)

A smart and interactive traffic signal management system built using **Design and Analysis of Algorithms (DAA)** concepts.
This system dynamically optimizes signal timing based on traffic density and provides a real-time simulation with control features.

---

## 🔥 Features

* 🚦 Dynamic Traffic Signal Optimization
* 🚑 Emergency Vehicle Priority Handling
* ⏱ Real-time Countdown Timer
* 🔄 Continuous Traffic Simulation
* ⏸ Pause / ▶ Resume / 🛑 Stop Controls
* 📊 Traffic Optimization Report
* 📄 PDF Report Export
* 🎨 Modern Responsive UI with Animation

---

## 🧠 Algorithms Used

* **Greedy Algorithm**
  Selects the road with the highest vehicle count first

* **Priority Scheduling**
  Ensures efficient allocation of signal timing

* **Queue-Based Simulation**
  Maintains continuous traffic flow in cycles

## 🎮 How to Use

1. Enter vehicle count for each road (A, B, C, D)
2. Click **Start Simulation 🚦**
3. Use controls:

   * ⏸ Pause
   * ▶ Resume
   * 🛑 Stop
4. Click **🚑 Emergency** for priority signal
5. Generate **Report 📄**
6. Download **PDF 📥**
